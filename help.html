Help & Setup Guide

to get Kenowa running

Follow the steps below to activate your AI key or update to the latest version of the extension.

Get Your Gemini API Key
1
Open Google AI Studio
Click the button below to visit Google AI Studio. Sign in with your Google account if prompted.
Open Google AI Studio
2
Click "Create API Key"
Once logged in, click the blue Create API key button. Select "Create API key in new project" or pick an existing project.
3
Copy Your Key
Your API key will appear — click the copy icon next to it. It usually starts with AIza...
4
Paste Into Kenowa AI
Open the Kenowa AI extension → Settings → paste your key into the Gemini API Key field → Save Changes.

Delete the Old Extension Folder
Find where you originally extracted the old Kenowa folder on your computer. Select it and delete it — or you can replace it by extracting the new ZIP into the same location.
Tip: If you extract the new ZIP into the exact same folder path, Chrome will automatically use the updated files.
Open Chrome Extensions Page
In your browser address bar, type chrome://extensions and press Enter. Or go to Menu → More Tools → Extensions.
