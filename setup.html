Installation Steps
1

Download the Extension

Click the Download Kenowa AI button above. A file named kenowa-ai.zip will be saved to your Downloads folder.

💡 Make sure your browser doesn't block the download. If it does, click Keep in the download bar.
2

Extract the ZIP File

Locate kenowa-ai.zip in your Downloads. Right-click it and choose Extract All… (Windows) or double-click it (Mac) to unzip.

You should now have a folder called kenowa-ai containing files like manifest.json, sidepanel.html, background.js, etc.

⚠️ Do not delete or move this folder after installation — Chrome loads the extension directly from it.
3

Open Chrome Extensions Page

Open Google Chrome and type this in your address bar, then press Enter:

chrome://extensions

This opens the Extensions management page.

4

Enable Developer Mode

In the top-right corner of the Extensions page, toggle Developer mode to ON. A blue toggle means it's enabled.

Three new buttons will appear: Load unpacked, Pack extension, and Update.

✓ Developer mode is required to load unpacked extensions
5

Load the Extension Folder

Click Load unpacked. A file picker will open. Navigate to and select the kenowa-ai folder you extracted in Step 2.

Click Select Folder. Kenowa AI will immediately appear in your extensions list with its icon.

💡 Select the folder itself — not a file inside it. The folder must contain manifest.json at its root.
6

Pin Kenowa AI to Your Toolbar

Click the puzzle piece icon (🧩) in Chrome's toolbar. Find Kenowa AI Assistant in the list and click the pin icon 📌 next to it.

The Kenowa AI icon will now appear in your toolbar. Click it to open the side panel, or use the keyboard shortcut Ctrl+Shift+K (Windows) / ⌘+Shift+K (Mac).

✓ Installation complete — Kenowa AI is ready!
First Launch Setup
A

Create or Log In to Your Account

Open the Kenowa side panel and click Sign In. If you don't have an account yet, switch to the Sign Up tab and register with a username and password.

Your account syncs your settings, API keys, and exam answers across devices.

B

Add Your AI API Key

Click the ⚙️ Settings icon inside the panel. Under AI Provider, choose your provider and paste your API key:

Gemini (Google): Get a free key at aistudio.google.com
OpenRouter: Get a key at openrouter.ai

🔒 Your API key is stored locally and synced encrypted to the server. It is never shared.

Frequently Asked Questions
Will I lose my extension if Chrome updates?
Unpacked extensions stay installed across Chrome updates. However, Chrome may occasionally show a warning asking you to re-enable developer mode. Simply click Keep it and your extension continues working. The extension folder on your computer must not be deleted or moved.
Why does Chrome say "Extension may be unsafe"?
This warning appears for all unpacked (developer-mode) extensions since they aren't published to the Chrome Web Store. Kenowa AI is safe — you downloaded it directly from kenowa.synergize.co. Click Keep it to dismiss the warning.
How does Exam Mode detect questions?
Exam Mode reads the visible text of the active exam tab and sends it to your chosen AI model, which identifies multiple-choice questions and returns the correct answers as a JSON array. The answers are then matched and clicked on the page automatically. The same question answered once is cached — every repeat is instant.
What is the QA Training Cache exactly?
Every time the AI answers an exam question, the question text (hashed for privacy) and the answer are saved to the server database. The next time the same question appears — for any user — the cached answer is returned immediately without calling the AI API at all. Admin-verified answers are marked as confidence 100 and can never be overwritten. This means the system gets faster and more accurate with every exam session.
How do I update to a new version?
Download the new ZIP from this page, extract it to the same folder (replace all files), then go to chrome://extensions and click the reload icon (↺) on the Kenowa AI card. Your settings and account are preserved — they are stored server-side.
Can multiple people use the same account?
Kenowa AI uses single-device session tokens. If you sign in on a second device, the first device will be signed out automatically. Use separate accounts for separate users. Pro users have extended features — contact your administrator for Pro access.
I can't load the extension — what should I check?
Make sure: (1) Developer mode is toggled ON in chrome://extensions, (2) you selected the folder (not a file), (3) the folder contains manifest.json at its root. If you see a red error badge on the extension card, click Errors to read the details and report them at kenowa.synergize.co.
