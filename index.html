Capabilities

Engineered For Performance & Privacy

Built from the ground up as a native Manifest V3 Chrome Extension.

Local Ollama (Offline AI)

Direct connection to your local machine at http://localhost:11434. Zero API keys required. 100% private and offline capable.

Ollama Cloud (Hosted GPU)

Connect to datacenter-grade hardware via ollama.com/api. Run 70B+ parameter models without taxing your laptop hardware.

Personal Capsule RAG

Save up to 5 Markdown documents locally. Kenowa extracts relevant sections and embeds verifiable source citations directly beneath every answer.

Expandable Citations

Collapsible drawer under AI responses keeps your chat clean while letting you verify exact source quotes and document origin on demand.

Auto GitHub Release Check

In-app release monitor checks GitHub releases automatically and alerts you whenever a new version is available with a 1-click update download.

Local AES Encryption

All credentials and history remain in Chrome’s sandboxed local storage with client-side encryption. Zero tracking servers. Zero telemetry.
